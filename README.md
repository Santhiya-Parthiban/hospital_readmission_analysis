# Hospital Readmission Analysis

## Overview
This project explores hospital readmission patterns using SQL queries on a healthcare dataset.  
The goal is to uncover insights about hospital performance, patient outcomes, and the measures most associated with high readmission rates.

## Features
- Count of unique hospitals in the dataset  
- Average predicted readmission rates by **State**  
- Facility-level ranking by predicted readmission rate  
- Average readmission rates by **Measure Name**  
- Overall readmission rate across all hospitals  
- Identification of the **highest average readmission measure per State**  
- Identification of the **highest average readmission measure per Facility**

## Tech Stack
- **Database:** MySQL  
- **Language:** SQL
